# Шаблон Word-транскрипции лекций (для программы транскрибации)

Цель: папка `.docx` сразу пригодна для `tools/lectures` → ОДИН `lectures_clean.db` →
импорт в приложение (Настройки → `.db`) в раздел «Лекции Шьямакунды Прабху»
как ОДНА книга: произведение → разделы → главы → лекции.

## Модель: один файл = одна лекция

Никакой разметки внутри документа не нужно — обычный текст лекции абзацами.
Вся иерархия — **в имени файла**:

```text
<номер> (<песнь>.<глава>.<тексты>) [<заголовок>].docx
```

- `<номер>` — порядковый номер файла (001, 338, …). Для сортировки НЕ используется,
  только чтобы имена не colliding.
- `<песнь>` — раздел: для ЧЧ `1`=Ади-лила, `2`=Мадхья-лила, `3`=Антья-лила;
  для ШБ — номер песни 1..12; для БГ всегда `1`.
- `<глава>` — номер главы внутри раздела (для БГ — глава 1..18).
- `<тексты>` — номер стиха или диапазон (`1-36`, `82-120`), по которому лекция.
- `<заголовок>` — необязательный короткий заголовок (станет названием лекции в списке).
  Нет заголовка — возьмётся первая строка текста, иначе «Лекция NNN».

Примеры имён:

```text
001 (2.3.1-36).docx
338 (1.6.82-120) Величие Адвайты Ачарьи.docx
012 (1.2.13) Душа и тело.docx
```

Парсер терпимый к реальным именам из архива — всё ниже тоже разберётся:

```text
229 (3.4206-3.5.20).docx        -> песнь 3, гл.4 ст.206 — гл.5 ст.20 (кросс-главы, точка потерялась)
ОЯ (2.11.196-211.docx           -> префикс любой, скобка может быть не закрыта
4236 079 (2.14.90-141.docx       -> то же
2453 096(2.16.1-74, 82-115).docx -> несколько диапазонов через запятую
5041.docx                        -> без скобок: раздел «Разное», сортировка по номеру
```

Файл без скобок в имени (например `вводная беседа.docx`) не теряется —
попадёт в раздел «Разное» в конце книги (сортировка — по ведущему числу в имени).

Файл `000 <Произведение>` без скобок (`000 Чайтанья Чаритамрита.docx`) —
вводная лекция: называется «Введение» и показывается первой главой первого раздела
(отдельной плитки раздела под неё нет).

## Как строится название в списке (как у лекций Прабхупады — только имя)

- `029 (2.8.134-149) Сварупа Кришны` → **Лекция №29 по стихам 134-149 — Сварупа Кришны**
- `028 (2.8.117-133)` → **Лекция №28 по стихам 117-133** (без заголовка — только номер)
- В списке глав — только эти названия (+ нумерация `ЧЧ 2.8.134-149` подписью),
  тело лекции открывается по тапу. Сортировка — по нумерации стихов, не по имени файла.

Старый бинарный `.doc` читается напрямую (свой ридер, без зависимостей);
`.docx` с неверным расширением `.doc` — тоже. Качество извлечения проверяй через `scan`
(число слов + первые строки должны быть осмысленными).

## Что получится в приложении (пример ЧЧ)

- Книга «Чайтанья Чаритамрита. Лекции» (тип `SCC`, автор задаётся при сборке).
- Плитки разделов: Ади-лила, Мадхья-лила (+ «Разное», если есть файлы без привязки).
- Внутри раздела — плитки глав («Глава 6»).
- Внутри главы — список лекций **по возрастанию текстов** (`82-120` идёт как 82).
- Тап открывает полный текст лекции. Привязка (`ЧЧ 1.6.82-120`) лежит в пословнике —
  лекция находится поиском по номеру стиха.
- Номера стихов в тексте (`8.134`, `1.6.82`, `ЧЧ Ади Лила 1.1`) — кликабельные ссылки
  на русскую Чайтанью Чаритамриту (назад — системной кнопкой в лекцию).

## Правила для транскрибатора

1. Один `.docx` — строго одна лекция, не склеивать несколько.
2. Имя файла — по форме выше; песнь/глава/тексты — по стиху, по которому читалась лекция.
3. Тело — полный текст лекции абзацами (2–5 предложений на абзац), пунктуация проставлена,
   имена и термины единообразны. Санскрит/пословник/перевод НЕ выдумывать.
4. Старый бинарный `.doc` — сохранить как `.docx`.

## Проверка перед сборкой

```bat
cd tools\lectures
py lectures_build.py scan "папка-с-лекциями"
py lectures_build.py build lectures.json lectures_clean.db --force
```

`scan` покажет, как файлы разложатся (песнь.глава.тексты | заголовок) и что уйдёт в «Разное».
Или то же мышью: `tools\dbcomposer\py gui.py` → «📖 Лекции DOCX».

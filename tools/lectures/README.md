# lectures — балк-конвертация лекций Шьямакунды прабху в базу приложения

PC-тулза, только Python 3.8+, без зависимостей (как `dbcomposer`). Исходные `.docx` не трогаем.

## Модель: папка = ОДНА книга, файл = ОДНА лекция

`.docx` по `TEMPLATE.md` → ОДИН `lectures_clean.db` (таблицы `books/chapters/songs/textnums/texts` —
тот же формат, что ждёт `LibraryDbImporter`) → импорт в приложение (Настройки → `.db`).

Иерархия — из имени файла (`001 (2.3.1-36)`, `338 (1.6.82-120) Величие Адвайты Ачарьи`):
песнь → раздел (Ади/Мадхья/Антья-лила, Песни ШБ), глава → плитка главы,
лекции внутри главы — по возрастанию текстов. Сортировка — по (песнь, глава, текст),
НЕ по номеру файла. Файлы без скобок в имени уходят в раздел «Разное» в конце.

Одна лекция = одна строка `textnums/texts` (как стих в исходном формате).
В приложении: заголовок → `text`, полный текст → `translation`,
привязка (`ЧЧ 1.6.82-120`) → `synonyms` (поиск по номеру стиха находит лекцию),
имя файла → `comment`. Раздел «Лекции Шьямакунды Прабху» — после патча секции (см. ниже).

## Команды

```bat
cd tools\lectures
py lectures_build.py scan "папка-с-лекциями"
py lectures_build.py build lectures.json lectures_clean.db --force
py lectures_build.py spec   :: пример спеки
```

`scan` — проверка разбора без записи (как разложатся файлы + что уйдёт в «Разное»).
`inspect file.docx` — старый режим «файл = книга» (маркеры КНИГА/… внутри, для совместимости).

Окно в `dbcomposer` (`py gui.py` → кнопка «📖 Лекции DOCX»): та же сборка мышью —
название/автор/тип книги + ОДНА обложка JPEG сверху, «+ Папка DOCX»,
таблица лекций (уже отсортирована), «СОБРАТЬ»,
«📲 На телефон (adb push)» в `/sdcard/Download` (без adb — вручную: приложение →
Настройки → `.db`).

## Файлы

- `lectures_build.py` — конвертер (stdlib only).
- `lectures.json` — спека сборки (одна книга).
- `TEMPLATE.md` — формат имён файлов и текста (дать транскрибатору).
- `TRANSCRIBE_PROMPT.md` — промпт для программы транскрибации (вшить как есть).

## Патч приложения (один раз на новый тип лекций, пример — SBRS/БРС)

Без него книга ляжет в «Остальное» и подпишется кодом типа:

1. `lectures_build.py`: `WORK_CODE` (`"SBRS": "BRS"`), `DEFAULT_SONGS`,
   `WORK_SHORT` (`"SBRS": "БРС"`), `WORK_SONG_NAMES` (разделы).
2. `lectures_gui.py`: `BOOK_TYPES` + `TYPE_HINT`.
3. Приложение:
   - `ReaderSettings.defaultSection()`: `"SBRS" -> 0` (или author-условие
     `contains("Шьямакунда")` — тогда коды вообще не важны);
   - `VerseShare.RU`: `"SBRS" to "БРС"`;
   - `VerseShare.isLectureBook` / `isLectureLike`: добавить `"SBRS"`;
   - `VerseDetailScreen` (lecCtx): `"SBRS" -> "BRS"` (код произведения для ссылок);
   - `LibraryDbImporter` bodyCap: добавить `"SBRS"` (тела лекций длинные);
   - `SettingsScreen` peekLang: добавить `"SBRS"` (всегда rus);
   - `HtmlText.GR_CODE`: `"BRS", "SBRS"`.
4. Ссылки `БРС x.y.z` оживают, когда в приложении есть книга с типом `BRS`.

## Привязка без номеров в именах

Файлы вида `БРС 001` (только номер лекции) привязываются по шапке тела:
первые 12 абзацев ищутся на `N (песнь.глава.стихи[-])` — например,
`6 (1.1.2-3)` или `1 (1.1.1. Мангала текст)`. Имя файла в привязке не участвует.
Ведущие титульные абзацы (символьный мусор DOC-шрифтов, голый титул
произведения) выкидываются целиком — в текст лекции они не идут.

# Промпт для программы транскрибации (вшить как есть)

Твою расшифровку заберёт автоматический конвейер, поэтому выдай результат
СТРОГО в следующем виде. Никаких пояснений вне документа.

1. Один аудиофайл/одна лекция = ОДИН документ Word (.docx).
2. Имя файла — строго по форме (без кавычек):
   `<номер> (<песнь>.<глава>.<тексты>) [<заголовок>]`
   - `<номер>` — порядковый номер (001, 002, …).
   - `<песнь>` — для Чайтанья Чаритамриты: 1=Ади-лила, 2=Мадхья-лила, 3=Антья-лила;
     для Шримад-Бхагаватам — номер песни 1..12; для Бхагавад-гиты — всегда 1.
   - `<глава>` — номер главы; `<тексты>` — номер стиха или диапазон (1-36, 82-120),
     по которому читалась лекция. Лекция через границу глав: `(3.4.206-3.5.20)`.
     Если стих неизвестен — скобки опустить целиком (тогда только номер).
   - `<заголовок>` — короткий заголовок по смыслу (3–7 слов), можно опустить.
   - Примеры: `001 (2.3.1-36)`, `338 (1.6.82-120) Величие Адвайты Ачарьи`.
3. Тело документа — полный текст лекции абзацами (один абзац = одна мысль, 2–5 предложений).
   Убери слова-паразиты распознавания, проставь пунктуацию, имена и термины — единообразно.
   Санскрит/пословник/перевод НЕ выдумывай — только живая речь лектора.

Запрещено:
- сливать две лекции в один файл; делить одну лекцию на части;
- менять порядок изложения исходника;
- выводить что-либо кроме документа и имени файла (без преамбул вида «Вот транскрипция»).

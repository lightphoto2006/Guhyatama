# Пошаговые сценарии

Схема каждого сценария: что хотим → откуда начинаем → куда нажимаем →
что видим → дальше → как понять, что получилось.

## С1. Открыть главу «Шримад-Бхагаватам», Песнь 1

- Хотим: почитать начало первой песни.
- Начинаем: главный экран (📚).
- Нажимаем: карточку «Шримад Бхагаватам» → плитку «Песнь 1 «Творение»».
- Видим: плитки глав («Глава 1», «Глава 2», …) с числом стихов.
- Дальше: нажимаем «Глава 1» → список стихов.
- Получилось: в шапке название главы, ниже идут строки стихов.

Условие: книга должна быть импортирована (иначе её карточки нет на полке).

## С2. Найти слово «преданный» во всех книгах

- Хотим: все места со словом.
- Начинаем: вкладка 🔍.
- Нажимаем: поле «Поиск по всем книгам», вводим «преданный».
- Видим: строки «Книга · номер» с отрывками, совпадение подсвечено зелёным.
- Дальше: нажимаем строку → стих открывается ровно на совпадении.
- Получилось: читаем стих, слово подсвечено жёлтым.
- Вариант: переключатели «Санскрит / Стих / Коммент.» ищут только в части
  стиха; «RU / EN» — только в книгах языка.

## С3. Узнать перевод санскритского слова

- Хотим: что значит слово из пословника.
- Начинаем: открытый стих, блок пословника (строки «слово — перевод»).
- Нажимаем: на жирное слово.
- Видим: экран ««слово» — N» со строками из других стихов.
- Дальше: переключатель «Все языки» показывает и неродные книги;
  тап по строке ведёт к стиху.
- Получилось: видим, как слово переводится в разных местах.

## С4. Сохранить фрагмент в заметки и вернуться к нему

- Хотим: не потерять мысль из комментария.
- Начинаем: открытый стих.
- Нажимаем и держим палец на начале фрагмента, растягиваем выделение,
  в меню жмём «В заметку».
- Видим: меню закрылось, ничего больше не произошло — так и должно быть.
- Дальше: вкладка 📓 → строка с подписью стиха и датой.
- Получилось: тап по строке снова открывает тот стих.

## С5. Задать вопрос к стиху

- Хотим: записать вопрос с цитатой.
- Начинаем: открытый стих, выделенный фрагмент, меню → «Вопрос».
- Видим: редактор «Новый вопрос», цитата уже подставлена в «Отрывок:».
- Дальше: заполняем «О чём вопрос» и «Текст вопроса», жмём «Сохранить»
  (серая, пока поля пусты).
- Получилось: вкладка ❓ → строка «1. БГ 2.13 — тема». Тап — правка,
  «›» — к стиху, «×» — удалить.

## С6. Слушать стих

- Хотим: послушать вместо чтения.
- Начинаем: открытый стих.
- Нажимаем: «▶ Слушать» (запись) или «▶ Слушать (TTS)» (голос телефона).
- Видим/слышим: кнопка стала «■ Стоп», идёт звук. Повторное нажатие —
  остановка.
- Если вместо звука окно «Нет синтеза речи»/«Нет голоса» — идём
  по его кнопкам («Установить» / «Настройки речи») и скачиваем голос.
- Получилось: звук идёт, кнопка останавливает.

## С7. Открыть лекцию и перейти к стиху из неё

- Хотим: послушать/почитать лекцию, заглянуть в цитируемый стих.
- Начинаем: раздел «Лекции Шьямакунды Прабху» → книга
  «Чайтанья Чаритамрита. Лекции» → «Мадхья-лила» → глава → лекция
  («Лекция №29 по стихам 134-149 — Сварупа Кришны»).
- Видим: название, подпись-номер, полный текст. Номера стихов в тексте
  подсвечены как ссылки.
- Дальше: нажимаем номер (например, «8.134») → открывается стих
  «ЧЧ 2.8.134» из русской «Чайтанья Чаритамриты» (если она загружена,
  иначе — сообщение, какой книги не хватает).
- Получилось: прочитали стих; кнопка «назад» вернула в лекцию.

## С8. Вернуться к чтению через закладку

- Хотим: продолжить с сохранённого места.
- Начинаем: главный экран, карточка книги со звездой ★.
- Нажимаем: на звезду (не на карточку).
- Видим: открылась глава на том же месте списка (или сразу стих).
- Получилось: читаем дальше. Снять закладку — нажать горящую ★ ещё раз.

## С9. Увеличить шрифт и выровнять текст

- Хотим: крупнее буквы, ровный правый край.
- Начинаем: ⚙️ → разделы «Шрифт стиха» / «Шрифт списка главы».
- Нажимаем и тянем ползунки (12–30), цифра показывает размер.
- Дальше: «Выравнивание текста» → «По ширине».
- Быстрый путь: на открытом чтении кнопки громкости телефона меняют
  шрифт этого экрана.
- Получилось: текст стал крупнее/ровнее сразу, без перезапуска.

## С10. Сохранить всё перед переустановкой

- Хотим: не потерять заметки, вопросы, избранное.
- Начинаем: ⚙️ → раздел «Заметки и бэкап».
- Нажимаем: «Экспорт» → выбираем, куда сохранить `vedalibrary-notes.json`.
- Видим: сообщение «Бэкап сохранён».
- Дальше (на новом телефоне): те же шаги, но «Импорт» → выбрать файл.
- Получилось: вкладки 📓/❓/⭐ снова заполнены. Сами книги бэкапом
  не переносятся — их файлы `.db` импортируйте отдельно (сценарий из
  быстрого старта, шаг 1).

## С11. Удалить ненужную книгу

- Хотим: убрать книгу с полки.
- Начинаем: долгое нажатие на её карточку (или ⚙️ → «Книги по разделам» →
  корзина «🗑» у книги).
- Видим: окно «Удалить книгу?» с предупреждением о необратимости.
- Нажимаем: красную «Удалить» (или «Отмена», если передумали).
- Получилось: карточка исчезла. Вместе с книгой удаляются её закладка
  и привязанные заметки — сначала сделайте экспорт (С10).
